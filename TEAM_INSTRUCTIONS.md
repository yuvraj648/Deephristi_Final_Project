## 📌 What Is Uploaded vs. What Is NOT Uploaded

### ✅ What IS in the GitHub Repository:
1. **Full Source Code (330 files):**
   - Researcher eDNA Frontend (`E-DNA/project files/UI`)
   - eDNA FastAPI Backend & Logic (`E-DNA/project files/MODELS`)
   - Naval Surveillance Frontend (`SURVEILLANCE/DeepDrishti/frontend`)
   - Surveillance Express/MongoDB Backend (`SURVEILLANCE/DeepDrishti/backend`)
   - Computer Vision AI Engine (`SURVEILLANCE/DeepDrishti/model`)
2. **All 6 Pretrained Deep Learning Models (690 MB via Git LFS):**
   - Tara DNABERT-2 Model: `best_model.pt` (~447 MB)
   - FUNIE-GAN Generator: `model.pth` (~82 MB)
   - Underwater Object Detection & Depth Models (`.pth` files)
3. **Reference Datasets & Database:**
   - `asv_table.csv` (~63.6 MB)
   - `database.sqlite` (~52.8 MB)

### ❌ What is NOT in the GitHub Repository:
| Item | Why It's Excluded | What You Should Do |
| :--- | :--- | :--- |
| **`.env` files** | Contain sensitive passwords & database credentials. | Create your local `.env` files from `.env.example` or request them privately. |
| **`node_modules/`** | Contains thousands of auto-generated packages. | Run `npm install` locally. |
| **Python `venv/` & `__pycache__/`** | OS-specific binaries and compiled bytecode. | Run `pip install` into your local Python environment. |
| **`dist/` & `uploads/`** | Temporary build artifacts and runtime file uploads. | Auto-generated by the servers at runtime. |

## ⚙️ Initial Setup Guide for Team Members (One-Time)

### Step 1: Install Required Tools
Ensure you have the following installed on your machine:
1. **Git** with **Git LFS**: [Download Git](https://git-scm.com/) (Make sure Git LFS is enabled).
2. **Node.js** (v18 or v20 recommended): [Download Node.js](https://nodejs.org/)
3. **Python 3.10+**: [Download Python](https://www.python.org/)

---

### Step 2: Clone the Repository & Pull AI Models

Open Command Prompt (CMD) in the folder where you want to store the project (e.g., your Desktop):

```cmd
git clone https://github.com/yuvraj648/Deephristi_Final_Project.git
cd Deephristi_Final_Project
```

> [!IMPORTANT]
> **Crucial Step for AI Models (Git LFS):**
> You must run this command to download the real 690 MB PyTorch model weight files rather than small pointer text files:
> ```cmd
> git lfs install
> git lfs pull
> ```

---

### Step 3: Configure Environment (`.env`) Files

> [!NOTE]
> **Security Notice:** Secret keys, database connection strings, and credentials are intentionally omitted from GitHub.
> Ask the team lead (@yuvraj648) privately to share the project `.env` files, or use the `.env.example` templates to set your own:

#### 1. Surveillance Backend (`SURVEILLANCE\DeepDrishti\backend\.env`)
Create `SURVEILLANCE\DeepDrishti\backend\.env` with:
```env
PORT=5003
NODE_ENV=development
MONGODB_URI=your_mongodb_connection_uri_here
JWT_SECRET=your_jwt_secret_here
JWT_EXPIRE=7d
FRONTEND_URL=http://localhost:5173
API_VERSION=v1
API_BASE_URL=http://localhost:5003
```

#### 2. Researcher UI (`E-DNA\project files\UI\.env`)
Create `E-DNA\project files\UI\.env` with:
```env
VITE_SUPABASE_URL=your_supabase_url_here
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here
```
*(Note: You can also simply click **"Continue in Offline Local Mode"** on the Researcher UI login screen without configuring Supabase).*

---

### Step 4: Install Dependencies

#### A. Node.js Dependencies (Run in 3 folders)

1. **Researcher UI:**
   ```cmd
   cd "E-DNA\project files\UI"
   npm install
   cd ..\..\..
   ```

2. **Surveillance Backend:**
   ```cmd
   cd "SURVEILLANCE\DeepDrishti\backend"
   npm install
   cd ..\..\..
   ```

3. **Surveillance Tactical Frontend:**
   ```cmd
   cd "SURVEILLANCE\DeepDrishti\frontend"
   npm install
   cd ..\..\..
   ```

#### B. Python Dependencies

Install the required Python packages:
```cmd
pip install fastapi uvicorn torch torchvision ultralytics opencv-python flask flask-cors pandas numpy scikit-learn
```

## 🚀 How to Run the Platform (5 Separate Terminals)

To avoid PC freezing and view live logs for each microservice, open **5 separate Command Prompt (CMD) windows** from the root repository folder (`Deephristi_Final_Project`):

---

### 🖥️ Window 1: eDNA AI Backend API (Port 8000)
*Taxonomic classification & bioinformatics analysis.*
```cmd
cd "E-DNA\project files\MODELS"
python -m uvicorn api:app --host 0.0.0.0 --port 8000 --reload
```
- **Address:** `http://localhost:8000`
- **Swagger Docs:** `http://localhost:8000/docs`

---

### 🖥️ Window 2: Researcher Hub UI (Port 5173)
*Marine biodiversity analytics workspace & visualizers.*
```cmd
cd "E-DNA\project files\UI"
npm run dev
```
- **Address:** `http://localhost:5173`
- **Login:** Click **"Continue in Offline Local Mode"** (or use local test credentials)

---

### 🖥️ Window 3: Computer Vision AI Server (Port 5001)
*FUNIE-GAN enhancement, YOLOv8 threat detection, and MiDaS depth estimation.*
```cmd
cd "SURVEILLANCE\DeepDrishti\model"
python app.py
```
- **Address:** `http://localhost:5001`

---

### 🖥️ Window 4: Surveillance Backend API (Port 5003)
*Node.js Express + MongoDB Atlas naval telemetry server.*
```cmd
cd "SURVEILLANCE\DeepDrishti\backend"
node server/server.js
```
- **Address:** `http://localhost:5003`

---

### 🖥️ Window 5: Tactical Surveillance Deck UI (Port 5175)
*Naval defense console & live underwater feed enhancement.*
```cmd
cd "SURVEILLANCE\DeepDrishti\frontend"
npm run dev
```
- **Address:** `http://localhost:5175`

## 🔄 Daily Collaboration Workflow (Avoid Conflicts!)

To keep the project clean and prevent merge conflicts between team members:

### 1. Before Starting Work (Always pull latest updates):
```cmd
git pull origin main
```

### 2. After Making Changes:
```cmd
git status
git add .
git commit -m "Description of changes made"
git push origin main
```

### 3. Rules to Follow:
- 🚫 **Never commit `node_modules` or `.env` files** (they are already excluded by `.gitignore`).
- 🚫 **Do not modify model files (`.pt`, `.pth`)** unless retraining is coordinated with the team.
- 💡 If working on a major feature, create a new branch:
  ```cmd
  git checkout -b feature/your-feature-name
  ```
  Once tested, merge it into `main`.
